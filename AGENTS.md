# Working Agreement

Before changing the student file interface, read and follow [`FILE_INTERFACE_SPEC.md`](./FILE_INTERFACE_SPEC.md). It is the maintained source of truth; update it alongside any changed product decision.

The original design study is [`im currently wanting to implemt an goodnotes style file manager fo typstify, i w-handoff.zip`](<./im currently wanting to implemt an goodnotes style file manager fo typstify, i w-handoff.zip>); read its `README.md` and primary `project/Typstify Library.dc.html` when visual context is needed.

Preserve the Classic interface as a working toggleable alternative. Reuse Typstify's existing Gio theme, workspace, file-opening, and filesystem-operation paths rather than duplicating them.
